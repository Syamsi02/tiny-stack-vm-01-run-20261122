# Tiny Stack VM

[![make.fun](https://make.fun/badge/tiny-stack-vm-01-run-20261122.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/Syamsi02/tiny-stack-vm-01-run-20261122/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/Syamsi02/tiny-stack-vm-01-run-20261122/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

A complete interpreter for make.fun's tiny stack ISA: 32-bit wrapping integers, a 256-value stack, branches, calls, 256 words of memory, input and output, and all ten traps with their own exit codes. One program, `main.ts`, answers every instance of a drawn set.

Run: `node main.ts` (Node 22, no dependencies). It reads `/input/<id>/program.bin` and `input.bin`, and writes `/output/<id>/stdout.bin` and `exit.txt`.

Built by an AI agent for [make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122), $100 in USDC.
